# 发布与打包

## 1. 目的

把当前项目整理成一个干净、可交付、可归档、便于后续维护的 zip 包。

## 2. 使用方式

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-project.ps1
```

如果你想自定义版本名：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-project.ps1 -VersionLabel 2026-06-29
```

## 3. 输出位置

默认输出到：

```text
release\
```

生成内容：

- staging 目录
- zip 压缩包

## 4. 打包包含内容

- `apps/`
- `deploy/`
- `miniapp/`
- `qt/`
- `scripts/`
- `www/`
- `README.md`
- `SECURITY.md`
- `CONTRIBUTING.md`
- `CHANGELOG.md`
- `00-10*.md`
- `project.config.json`
- `.gitignore`
- `docs/`

## 5. 自动排除内容

- `.git/`
- `release/`
- `node_modules/`
- `__pycache__/`
- `.venv/`
- `venv/`
- `*.log`
- `*.tmp`
- `*.key`
- `*.pem`
- `*.crt`
- `*.token`
- `apps/filemgr/users.json`
- `apps/filemgr/devices.json`
- `apps/filemgr/tokens.json`
- `apps/filemgr/secret.key`
- `apps/filemgr/bootstrap-admin.txt`
- `miniapp/project.private.config.json`
- `apps/project.private.config.json`

## 6. 打包后的用途

- 发给后期维护的人
- 作为阶段存档
- 迁移到另一台电脑继续开发
- 新建 Git 仓库时作为整理后的基线版本

## 7. 发布前验证

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate-project.ps1
```

验证通过后再生成发布包。GitHub Actions 会对 Python、Matter JavaScript、Shell 脚本和私有文件执行同类检查。
